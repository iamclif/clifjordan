# clifjordan

Personal site built with a minimal Express + Nunjucks setup.

## Requirements

- Node.js 18 or newer

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Development mode

For automatic server restarts and browser refresh while editing templates, CSS, or JS:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
